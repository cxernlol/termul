The Troupe window has four parts: the sidebar on the left, the main area with your tabs, the tool strip on the right edge, and the right panel that the tool strip opens.

<Callout type="info">The picture below shows an older layout, with a side panel, a tab bar menu, and a status bar. It will be replaced. The sections on this page describe the current window.</Callout>

![The Troupe window in an older layout, with the projects list, a side panel, the tab bar, an agent chat, and a status bar](/screenshots/getting-started-window.png)

## 1. The sidebar

The column on the far left holds your projects and their chats. From top to bottom it has these parts:

- **New chat** starts a chat in the active project. With no project open, it starts a [quick chat](/docs/agents/start-a-chat).
- **Search** opens the [command palette](/docs/getting-started/command-palette), where you can also find chats.
- **Canvas** opens the project's design document (a `.figcraft` file in the project folder) in a tab. If the project has no such file, you start with an empty design.
- **Automations** opens the project's [automations](/docs/automations).
- **Projects** lists your projects. Its **+** menu has **New project**, **New folder group**, and **Import chats**. Select a project to switch to it. Each project shows its chats under its name. See [Manage projects](/docs/getting-started/projects).
- **Quick chats** lists chats that don't belong to a project, and **Older chats** keeps chats from older versions of Troupe. See [Chat history](/docs/agents/chat-history).
- At the bottom are **Settings**, **Report a bug**, **Color themes**, and the keyboard shortcuts menu. The shortcuts menu opens the **Shortcut Menu**, where you can change common shortcuts.

Press `Ctrl+B` (`Cmd+B` on macOS) to collapse the sidebar to a narrow strip of icons, or to expand it again. The button at the top of the sidebar does the same. While the sidebar is collapsed, that button sits at the left end of the row above the main area. You can also drag the right edge of the sidebar to change its width.

When the sidebar is collapsed, it shows icons for the same parts. A small dot on a chat's icon shows its status. Hover over or focus an icon to see its name, or a project's chats.

On Windows and Linux, the window buttons (minimize, maximize, and close) are at the top right of the window. On macOS, the window buttons sit in the sidebar and hide while it is collapsed. To make the sidebar translucent on macOS, see [App settings](/docs/settings/app-settings#translucent-sidebar).

## 2. The main area

The main area shows your tabs. Each open chat, terminal, file, and Git view is a tab. Select a tab to show it. To close a tab, select its **×**, middle-click it, or press `Ctrl+W` (`Cmd+W` on macOS, `Alt+W` in the browser).

Right-click a tab for more actions, such as **Rename** for a terminal, **Close Other Tabs**, and **Copy Path** for a file.

You can show several tabs side by side. Drag a tab to the left, right, top, or bottom edge of the main area to split it. You can also drag a chat from the sidebar into a pane. See [Terminals](/docs/terminals) for tabs and panes in detail.

A new chat opens with **What should we do in** _project_**?** and a message box. Type what you want an agent to do and press `Enter`. Under the message box, choose where the agent works: the current checkout, an existing worktree, or a new worktree. See [Start a chat](/docs/agents/start-a-chat).

## 3. The tool strip

The narrow strip on the right edge of the window has these buttons. Hover over a button to see its name.

- **Explorer** shows the files in the project folder. See [Files](/docs/files).
- **Changes** shows the files you changed, and lets you stage and commit them. The number on the button counts the changed files. See [Git](/docs/git).
- **GitHub** lists the issues and pull requests of the project's GitHub repository. See [GitHub issues and pull requests](/docs/git/github).
- At the bottom, **New terminal** opens a terminal in the working folder. Right-click it to pick a shell. See [Open a terminal](/docs/terminals/open-a-terminal).
- In the desktop app, **New browser tab** opens a web page inside Troupe. See [Browser](/docs/browser).
- In the desktop app, a monitor icon for [remote access](/docs/remote/share-desktop). In the browser, a dot that shows the connection to the server instead. If the server goes offline, select the dot to try again.

## 4. The right panel

**Explorer**, **Changes**, and **GitHub** open in the panel at the right of the main area. Click the same button again, or **Close panel** at the top of the panel, to close it. Press `Ctrl+Alt+B` (`Cmd+Option+B` on macOS) to show or hide the panel. Drag its left edge to change its width. While a quick chat is open, the three buttons and the panel are hidden. Go back to a project to use them.

To work in one of the project's Git worktrees, open the project's menu in the sidebar and choose **Switch worktree…**. The chats in the sidebar and the **Changes** panel follow your choice. **New terminal** opens in the folder of the active tab, for example a chat that runs in another worktree, and in the picked worktree when the active tab has no folder. See [Worktrees](/docs/git/worktrees).

## On a phone

On a narrow screen, such as a phone, Troupe uses a different layout. The sidebar, the tool strip, and the tab bar are hidden. Select the menu button at the top left to open the drawer and switch between chats, terminals, and open files. See [Browser and phone](/docs/remote).
